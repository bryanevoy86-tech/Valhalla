================================================================================
HOW IT WORKS
================================================================================

1. On startup: Logging is configured with INFO level and stdout output
2. Each request: RequestLoggingMiddleware logs incoming request details
   - HTTP method and endpoint path
   - Client IP address
   - Timestamp

3. Each response: Middleware logs response details
   - Status code
   - Response timestamp
   - Total request duration


================================================================================
LOG FORMAT
================================================================================

Requests:
  "2026-04-02 10:30:45,123 - app.core.error_logging - INFO - 
   Incoming request: POST /api/deals | Client: 192.168.1.1"

Responses:
  "2026-04-02 10:30:45,245 - app.core.error_logging - INFO - 
   Response sent: POST /api/deals | Status: 201"


================================================================================
INTEGRATION WITH SANITIZATION
================================================================================

Request Flow:
  1. Client submits form with potential XSS/SQL payload
  2. RequestLoggingMiddleware logs incoming request
  3. Sanitization module removes HTML tags and dangerous protocols
  4. Validation module checks business rules
  5. Database layer uses parametrized queries (SQL protection)
  6. Response is returned
  7. RequestLoggingMiddleware logs response status and timing

Result: Full audit trail of all API activity with sanitization protection
